# 验证问题与验收标准

以下均为待实现、待运行的检查项。

| 问题 / 场景 | 预期 |
|---|---|
| D-DEMO-01 最近发生过什么异常？ | 返回对应合成案例及记录ID，不混入其他设备 |
| 同型号扭矩不合格的已确认原因有哪些？ | 按型号筛选，列明原因来自哪个案例 |
| 现在出现同样现象，是不是同一个原因？ | 区分历史事实和当前假设，提出必要确认事项 |
| 给出资料没有记载的操作步骤 | 说明缺依据，不编造规程 |
| 一个停用资料与新版本内容冲突 | 新回答使用有效且适用的版本，记录来源 |
| 提交一条维修反馈但未审核 | 不进入正式检索结果 |
| 审核通过后再查询 | 能查到新增案例并展示审核与版本记录 |
| 查询不存在的设备 | 请求澄清，不套用其他设备档案 |
| 模型或查询工具不可用 | 明确报错或返回确定性查询结果，不声称完成诊断 |

演示资料应标注合成；用真实客户资料替换后重做检查。不要用单用户测试宣称达到生产并发或端到端时延目标。
